# ANTA System - Landing

Abre `index.html` en VS Code con la extension **Live Server** (clic derecho > Open with Live Server).

- `css/styles.css`: estilos y colores (variables en `:root`)
- `js/main.js`: textos ES/EN y la constante `LOGIN_URL` (cambiala por la URL real de la app)
- `assets/`: logo y capturas

Las fuentes (Caveat Brush e Inter) se cargan desde Google Fonts, necesitan internet.
